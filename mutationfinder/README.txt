  It reads human_HBB_healthy.fasta and human_HBB_diseased.fasta,
  compares the sequences, and prints the location and details
  of the nonsense mutation.


HOW TO COMPILE AND RUN

JAVA

  Compile:
    javac FASTParsing.java GCContent.java

  Run Part 1 and 2 (FASTA Parsing + K-mer Analysis):
    java main in class FASTAParsing
    - You will be prompted to enter the file paths for the two .fasta files that are provided in the assignment (Zebrafish_TP53_Exons.fasta and Human_TP53_Exons.fasta)
    - You will then be prompted to enter an integer k

  Run Part 3:
    java main in class GCContentCalculator
    - No user input required
    - Hardcoded to read Human_TP53_Introns.fasta and Human_TP53_Exons.fasta
    - Outputs gc_data.csv in the same directory

PYTHON

  Requirements: Python 3, matplotlib
  Install matplotlib if needed:
    pip install matplotlib

  Run Part 4:
    python data_visuals.py
    - Reads gc_data.csv (must be generated by GCContent.java first)
    - Outputs gc_plot.png in the same directory

  Run Extra Credit:
    python find_the_mutation.py
    - Reads Human_HBB_healthy.fasta and Human_HBB_diseased.fasta
    - Prints the location and details of the nonsense mutation
